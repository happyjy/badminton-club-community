# 대회 참가 신청 양식 (외부 신청자용)

아래 형식 그대로 작성해서 보내주세요. 받은 내용을 그대로 시스템에 등록합니다.

---

## 1. 공통 정보 (신청 1건당 1번만 작성)

```
[입금자명] 홍길동
[팀명] 우리클럽 A팀
[개인정보 동의] 동의
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 입금자명 | **필수** | 실제 참가비를 입금하는 사람 이름. 입금 확인에 사용합니다. |
| 팀명 | 선택 | 대회에서 팀명을 받는 경우에만 작성. 없으면 `[팀명] -` |
| 개인정보 동의 | **필수** | `동의` 라고 적어주세요. 미기재 시 접수 불가. |

> 개인정보 동의 문구: 수집한 정보(이름, 생년월일, 전화번호)는 대회 참가 신청 목적으로만 사용되며 주최측에 제출됩니다.

---

## 2. 선수 명단

**같은 사람이 여러 종목에 나가도 명단에는 한 번만 적어주세요.**
선수 번호(선수1, 선수2…)는 아래 종목 신청에서 참조합니다.

```
[선수1]
이름: 홍길동
성별: 남
생년월일: 19900315
전화번호: 010-1234-5678
티셔츠: L

[선수2]
이름: 김영희
성별: 여
생년월일: 19880722
전화번호: 010-2345-6789
티셔츠: M
```

| 항목 | 필수 | 형식 | 예시 |
| --- | --- | --- | --- |
| 이름 | **필수** | 실명 | `홍길동` |
| 성별 | **필수** | `남` 또는 `여` 중 하나 | `남` |
| 생년월일 | **필수** | 숫자 8자리 `YYYYMMDD` | `19900315` |
| 전화번호 | **필수** | `010-0000-0000` | `010-1234-5678` |
| 티셔츠 | 선택 | 대회에서 지정한 사이즈 중 선택 | `L` |

**작성 시 주의**

- 생년월일은 하이픈 없이 숫자 8자리로 적어주세요. (미래 날짜·1900년 이전은 접수 불가)
- 전화번호는 휴대폰 번호로 적어주세요.
- 티셔츠 사이즈는 대회에서 티셔츠를 제공하는 경우에만 작성합니다.

---

## 3. 종목 신청

**종목 1개당 아래 블록을 하나씩 작성해주세요.**
같은 종목이라도 연령·급수가 다르면 별개 신청으로 각각 작성합니다.

```
[종목1]
종목: 남자복식
연령: 40대
급수: B조
선수: 선수1, 선수3

[종목2]
종목: 혼합복식
연령: 30대
급수: C조
선수: 선수1, 선수2
```

| 항목 | 필수 | 설명 |
| --- | --- | --- |
| 종목 | **필수** | 대회 요강에 있는 종목명 그대로 |
| 연령 | **필수** | 대회 요강에 있는 연령부 그대로 |
| 급수 | 대회에 따라 다름 | 급수를 쓰는 대회면 **필수**, 안 쓰는 대회면 `[급수] -` |
| 선수 | **필수** | 2번 명단의 선수 번호로 지정 |

**선수 인원 규칙**

| 종목 유형 | 필요 인원 | 예시 |
| --- | --- | --- |
| 복식 (남자복식·여자복식·혼합복식) | **2명** | `선수: 선수1, 선수2` |
| 단식 (남자단식·여자단식) | **1명** | `선수: 선수1` |

- 한 종목에 같은 선수를 두 번 적을 수 없습니다.
- 같은 종목 + 같은 연령 + 같은 급수 조합은 중복 신청할 수 없습니다.

## 접수 전 체크리스트

- [ ] 입금자명을 적었나요?
- [ ] 개인정보 동의를 `동의`로 적었나요?
- [ ] 모든 선수의 이름·성별·생년월일·전화번호를 빠짐없이 적었나요?
- [ ] 생년월일이 숫자 8자리인가요? (예: `19900315`)
- [ ] 전화번호가 `010-1234-5678` 형식인가요?
- [ ] 종목마다 인원이 맞나요? (복식 2명 / 단식 1명)
- [ ] 종목에 적은 선수 번호가 선수 명단에 있는 번호인가요?
- [ ] 같은 종목·연령·급수를 중복해서 적지 않았나요?
