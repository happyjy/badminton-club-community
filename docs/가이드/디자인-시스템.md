# 디자인 시스템 안내서

화면을 만들거나 고칠 때 보는 문서다. "무엇을 쓰는가"만 적는다.
왜 이렇게 정했는지는 [설계 문서](../superpowers/specs/2026-10-03-design-system-design.md)에 있다.

부품을 눈으로 보려면 개발 서버에서 `/dev/ui-kit`을 연다.

## 1. 원칙

| 원칙             | 내용                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 색·크기는 토큰만 | `bg-blue-500`, `#3b82f6`, `bg-white`, `text-sm`, `shadow-md`를 쓰지 않는다. 아래 토큰 이름만 쓴다                             |
| 부품 먼저        | 원시 `<input>`·`<select>`·`<textarea>`·`<button>` 모양을 직접 만들지 않는다. 부품이 없으면 `atoms`/`molecules`에 만든 뒤 쓴다 |
| 모노크롬         | 강조색은 `accent`(라이트 검정, 다크 흰색) 하나다. 색은 상태 칩과 프로필 사진이 맡는다                                         |
| 이모지 없음      | 아이콘은 `lucide-react`를 쓴다                                                                                                |
| 휴대폰 우선      | 터치 영역은 44px 이상. 입력칸 글자는 16px 이상(아이폰 확대 방지)                                                              |
| 라이트·다크      | 다크모드는 시스템 설정을 따른다. 토큰만 쓰면 자동으로 된다                                                                    |

## 2. 토큰

값의 원본은 `src/styles/globals.css`의 `:root`(라이트)와 `@media (prefers-color-scheme: dark)`(다크),
이름은 `tailwind.config.ts`에 있다.

### 색

| 용도                                         | 클래스                                                                                                |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 화면 바탕                                    | `bg-bg`                                                                                               |
| 카드·묶음·시트 바탕                          | `bg-surface` (`bg-surface-muted`)                                                                     |
| 눌린 듯한 회색 바탕 (보조 버튼, 칩 받침)     | `bg-fill`                                                                                             |
| `fill` 위에 떠 있는 것 (구분 버튼의 고른 칸) | `bg-raised`                                                                                           |
| 글자                                         | `text-primary` · `text-secondary` · `text-tertiary` (tertiary는 아이콘·안내용. 본문에 쓰지 않는다)    |
| 선                                           | `border-border` · `divide-separator`                                                                  |
| 강조                                         | `bg-accent` + `text-on-accent` (늘 짝으로 쓴다)                                                       |
| 상태                                         | `bg-positive-soft text-positive` · `warning` · `negative` · `neutral` (보통 `StatusChip`이 대신 쓴다) |
| 오버레이                                     | `bg-scrim` · `bg-tabbar` · `shadow-overlay`                                                           |
| 고정색                                       | `bg-kakao text-on-kakao` · `bg-avatar-1`…`6` + `text-on-avatar` (다크에서도 안 바뀐다)                |

### 글자 크기 (7단계)

`text-large-title`(28) · `text-title`(22) · `text-headline`(17) · `text-body`(16) · `text-callout`(15) · `text-footnote`(13) · `text-caption`(12)

굵기와 줄 높이가 함께 정해진다. PC 관리 화면(`data-density="compact"`)에서는 한 단계씩 작아진다.

### 그 밖

| 종류      | 값                                                                                           |
| --------- | -------------------------------------------------------------------------------------------- |
| 둥글기    | `rounded-sm`(8) · `rounded-md`(12, 관리 화면 PC에서는 8) · `rounded-lg`(16) · `rounded-full` |
| 겹침 순서 | `z-tabbar` < `z-dropdown` < `z-sheet` < `z-toast`                                            |
| 탭바 높이 | `var(--tabbar-h)`. 화면 아래에 붙는 요소는 이만큼 띄운다                                     |
| 전환 폭   | `lg`(1024px) 이상이 PC 배치                                                                  |

여러 클래스를 합칠 때는 `cn()`(`@/lib/utils`)을 쓴다.

## 3. 부품

| 하려는 것                          | 부품                                                                                                                    | 위치                             |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 버튼                               | `Button` — `variant`: primary · secondary · destructive · plain / `size`: lg(48) · md(44) · sm(32) / `pending`          | `atoms/buttons`                  |
| 아이콘만 있는 버튼                 | `IconButton` (`aria-label` 필수)                                                                                        | `atoms/buttons`                  |
| 입력                               | `Input` · `Select` · `Textarea` · `Checkbox`                                                                            | `atoms/inputs`, `atoms/Textarea` |
| 라벨 + 입력 + 오류 문구            | `FormField` (`label`, `error`, `required`)                                                                              | `molecules/form`                 |
| 상태 표시                          | `StatusChip` — `tone`을 직접 주거나 `domain` + `status`를 준다                                                          | `atoms`                          |
| 프로필 사진                        | `Avatar` (사진이 없으면 이름 첫 글자)                                                                                   | `atoms`                          |
| 불러오는 중                        | 목록은 `Skeleton`, 버튼 안은 `Button`의 `pending`                                                                       | `atoms`                          |
| 묶음 리스트                        | `ListGroup`(`label`, `footer`, `tone`) + `ListRow`(`title`, `subtitle`, `leading`, `trailing`, `href`/`onClick`)        | `molecules/list`                 |
| 2–4개 중 하나 고르기 (모두 보이게) | `SegmentedControl`                                                                                                      | `molecules`                      |
| 정렬·필터 고르기                   | `OptionPicker` (`aria-label`, `options`, `value`, `onChange`, `icon`, `align`). 휴대폰은 아래 시트, PC는 버튼 아래 메뉴 | `molecules`                      |
| 내용이 없을 때                     | `EmptyState`                                                                                                            | `molecules`                      |
| 쪽 넘김                            | `Pagination`                                                                                                            | `molecules`                      |
| 화면 제목                          | `PageHeader` (`title`, `subtitle`, `backHref`, `action`). 화면마다 하나                                                 | `organisms`                      |
| 떠 있는 창                         | `Sheet` (휴대폰은 아래 시트, PC는 가운데 모달. 제출 버튼은 `footer`에)                                                  | `organisms/sheet`                |
| 확인·경고                          | `const confirm = useConfirm()` → `await confirm({ title, destructive })`. `confirm()`·`alert()` 금지                    | `organisms/sheet`                |
| 표 (관리 화면)                     | `DataTable` + `Toolbar` + `BulkActionBar`                                                                               | `organisms/table`                |
| 알림                               | `toast.success()` · `toast.error()` (`react-hot-toast`)                                                                 | —                                |

### 고르는 부품 셋 중 무엇을 쓰나

| 상황                                     | 부품               | 이유                                                                  |
| ---------------------------------------- | ------------------ | --------------------------------------------------------------------- |
| 폼에 저장되는 값 (급수, 성별, 종목)      | `Select`           | 다른 입력칸과 모양이 같아야 하고, 항목이 많으면 OS 기본 목록이 편하다 |
| 화면을 보는 방식 (정렬, 필터, 보기 전환) | `OptionPicker`     | 입력칸이 아니라 보조 동작이다. 테두리 없는 글자 버튼으로 가볍게 둔다  |
| 2–4개를 늘 펼쳐 보여 주고 싶을 때        | `SegmentedControl` | 한 번에 고른다. 항목이 길거나 5개 이상이면 `OptionPicker`             |

`OptionPicker`의 PC 메뉴는 버튼 아래로 펼쳐진다. 넘치는 부분을 자르는 상자(`overflow-hidden`, 예: `ListGroup`) 안에 두지 않는다.

상태별 색은 `src/constants/statusTone.ts`에서만 정한다. 화면에서 `status === 'APPROVED' ? … : …`로 색을 고르지 않는다.
새 상태가 생기면 이 파일에 더한다.

## 4. 화면의 틀

뼈대(탭바·사이드바·여백)는 `Layout`이 그린다. 화면은 본문만 그린다.
새 화면이 관리용이면 `src/constants/layoutVariant.ts`의 `ADMIN`에, 메뉴에 넣으려면 `src/constants/navItems.ts`에 더한다.

### 회원용 화면

PC에서도 휴대폰과 같은 좁은 본문이다.

```tsx
<>
  <PageHeader title="게스트 신청" />

  <div className="space-y-6">
    <ListGroup label="내 신청 내역">
      {items.map((item) => (
        <ListRow
          key={item.id}
          title={item.name}
          subtitle={`방문 ${item.date}`}
          trailing={
            <StatusChip domain="guest" status={item.status}>
              {statusText(item.status)}
            </StatusChip>
          }
          href={`/clubs/${clubId}/guest/${item.id}`}
        />
      ))}
    </ListGroup>
  </div>
</>
```

### 관리용 화면

PC에서는 표, 휴대폰에서는 같은 데이터가 리스트로 바뀐다. 열 정의와 함께 "리스트에서 무엇을 보일지"를 적는다.
행을 누르면 상세 `Sheet`를 연다.

```tsx
<>
  <PageHeader title="회원 관리" />

  <Toolbar
    search={{ value: search, onChange: setSearch, placeholder: '이름 검색' }}
    summary={`총 ${rows.length}명`}
  >
    <OptionPicker aria-label="정렬" options={SORT_OPTIONS} value={sort} onChange={setSort} />
  </Toolbar>

  <DataTable
    aria-label="회원"
    rows={rows}
    rowKey={(row) => row.id}
    columns={[
      { key: 'name', header: '이름', cell: (row) => row.name, sortValue: (row) => row.name },
      { key: 'status', header: '상태', cell: (row) => <StatusChip … /> },
    ]}
    list={{
      title: (row) => row.name,
      subtitle: (row) => row.email,
      trailing: (row) => <StatusChip … />,
    }}
    onRowClick={openDetail}
    empty="등록된 회원이 없습니다."
    selection={{ selected, onChange: setSelected }}   // 일괄 동작이 있을 때만
    pagination={{ page, totalPages, onChange: setPage }} // 서버에서 쪽을 나눌 때만
  />

  <BulkActionBar count={selected.size} onClear={() => setSelected(new Set())}>
    <Button size="sm">납부 확인</Button>
  </BulkActionBar>
</>
```

참고할 실제 화면: `MembersView`(회원 관리), `GuestCheckView`(게스트 확인).

### 그리는 부분과 데이터를 나눈다

화면이 커지면 "그리는 부분"을 `…View` 부품으로 떼고, 페이지는 데이터를 읽어 넘기기만 한다
(`WorkoutDetailView`, `MembersView`, `GuestCheckView`). 이렇게 해야 테스트와 미리보기에서 가짜 데이터로 그릴 수 있다.

## 5. 새 색이 필요할 때

1. `globals.css`의 `:root`에 `--color-…`를 더하고, 다크에서 달라져야 하면 다크 블록에도 더한다.
2. `tailwind.config.ts`의 `colors`에 이름을 더한다.
3. 글자와 바탕으로 쓰이면 `src/__tests__/styles/darkMode.test.ts`의 `PAIRS`에 짝을 더한다(본문 4.5:1, 큰 글자·보조 3:1).

## 6. 확인하는 법

| 방법          | 내용                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 지킴이 테스트 | `npx jest src/__tests__/guards src/__tests__/styles` — 옛 색·이모지·hex, 부품을 안 쓴 입력 요소, `confirm()`·`alert()`, 다크 대비 |
| 미리보기 화면 | `/dev/ui-kit`, `/dev/shell-preview`, `/dev/screen-preview`, `/dev/admin-preview`. 로그인 없이 가짜 데이터로 본다. 운영에서는 404  |
| 봐야 할 조합  | 휴대폰(390)과 PC(1280), 라이트와 다크                                                                                             |

새 화면을 만들면 `…View` 부품을 미리보기 화면에 가짜 데이터로 올려 두면 로그인 없이 확인할 수 있다.
다크는 브라우저 개발자 도구의 렌더링 탭에서 `prefers-color-scheme`을 dark로 바꾸면 된다.
