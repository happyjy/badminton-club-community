# 회비 의무 시작 규칙 (가입 시기 반영)

## 목적

회원이 중간에 가입한 경우, **가입 이전 달 회비는 의무가 없음**을 시스템 전반에 반영하기 위한 규칙 정리.
또한 **휴회/병가 기간**에 해당하는 월도 의무에서 제외.

---

## 1. 기본 원칙

- **15일 규칙 (자동)**: 가입 신청 시점의 일자에 따라 `feeObligationStartAt`을 자동 설정.
  - **15일 이전(1~15일) 가입** → 당월 1일 (당월부터 회비 의무)
  - **15일 이후(16~31일) 가입** → 다음달 1일 (다음달부터 회비 의무)
  - 구현: `src/pages/api/clubs/[id]/join.ts`
- **관리자 조정**: 상황에 따라 **회비 입금 시작일**을 회원 상세에서 수동 설정 가능.
  - 이번 달부터: 해당 월 1일로 설정.
  - 다음 달부터: 다음 달 1일로 설정.

---

## 2. 연도 경계

- **가입 연도가 당해 연도보다 이전** → 당해 연도는 **1월~12월 전 구간** 회비 의무.
- **당해 연도에 가입** → 당해 연도는 **첫 의무월~12월**만 회비 의무.
- **당해 연도 이후 가입** → 당해 연도에는 회비 의무 없음.

---

## 3. 부부 회원

- 부부 행(한 건 입금에 두 명)의 경우, **둘 중 늦은 의무 시작월**을 기준으로 함.
- 양쪽 휴회 기간을 합산하여 의무 월 산출.
- 즉, 두 명 모두 회비 의무가 있는 달만 부부 행으로 집계/제안.

---

## 4. 휴회/병가 (MemberLeave)

### 4.1 개요

- 회원별로 휴회 기간을 등록하면 해당 월의 회비 의무가 제외됨.
- DB 모델: `MemberLeave` (startYear/startMonth ~ endYear/endMonth).
- 종료 미입력(null) 시 장기/미정 — 시작월 이후 모두 휴회로 처리.
- 여러 건의 휴회를 등록할 수 있음 (복수 기간 지원).

### 4.2 의무 월 계산 예시

```
예시: 4월 가입, 6~8월 휴회인 회원의 2025년 의무 월
→ [4, 5, 9, 10, 11, 12] (6, 7, 8월 제외)
→ totalMonths = 6

예시: 3월 가입, 3~5월 휴회 + 10~12월 휴회
→ [6, 7, 8, 9] (3, 4, 5, 10, 11, 12월 제외)
→ totalMonths = 4
```

### 4.3 대시보드 표시

- 휴회 기간에 해당하는 월은 대시보드에서 "의무 없음"으로 시각적 구분.
- 납부율 계산 시 의무 월(obligationMonths)만 분모로 사용.

---

## 5. 관리자 설정

- 회원별 **회비 입금 시작일**(`feeObligationStartAt`)은 **관리자가 설정**할 수 있음.
- 설정 위치: **클럽 멤버 관리 → 회원 상세** (가입일 표시 + 회비 입금 시작일 설정).
- 회비 대시보드/처리 화면에서는 **현재 값 표시**만 하고, 수정 시 "회원 정보에서 수정" 링크로 이동.
- 휴회 기간도 관리자가 등록/해제할 수 있음.
- API: `PATCH /api/clubs/[id]/membership-fee/members/[userId]/fee-obligation`

---

## 6. 데이터

### 6.1 회비 의무 시작

- `ClubMember.feeObligationStartAt` (DateTime?, nullable): 회비 의무가 시작되는 시점 (해당 연·월의 1일 등으로 설정해도 됨, 일자 무관).
- 미설정 시: 당해 연도 1월부터 의무로 간주 (하위 호환).
- **가입 신청 시**: 15일 규칙에 따라 자동 설정 (15일 이전 → 당월 1일, 16일 이후 → 다음달 1일).
- **승인 시**: `feeObligationStartAt`이 이미 설정되어 있으면 유지, 없으면 승인 시점(now())으로 설정.

### 6.2 휴회 기간

```prisma
model MemberLeave {
  id           Int    @id @default(autoincrement())
  clubMemberId Int
  startYear    Int
  startMonth   Int    // 1~12
  endYear      Int?   // null = 미정/장기
  endMonth     Int?   // 1~12
  reason       String?
}
```

## 7. 의무 계산 유틸리티

`src/lib/membership-fee/feeObligation.ts`에 다음 함수 제공:

| 함수                     | 설명                                           |
| ------------------------ | ---------------------------------------------- |
| `getObligationMonths`    | 해당 연도 의무 월 배열 (휴회 제외)             |
| `getFirstObligationMonth`| 해당 연도 첫 의무월 (1~12, 없으면 null)        |
| `isMonthObligated`       | 해당 연·월이 의무인지 boolean                  |
| `obligationMonthCount`   | 해당 연도 의무 개월 수                         |
| `isMonthInLeave`         | 해당 연·월이 특정 휴회 기간에 포함되는지       |
| `isMonthInAnyLeave`      | 해당 연·월이 휴회 기간 배열 중 하나에 포함되는지 |
