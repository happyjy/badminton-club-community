# 미납 탭 — 기준월 필터 공유

작성일: 2026-05-09
관련 화면: `/clubs/[id]/membership-fee`
관련 파일:

- `src/pages/clubs/[id]/membership-fee/index.tsx`
- `src/components/organisms/membership-fee/PaymentDashboardTable.tsx`

## 1. 배경 (Why)

대시보드 회원별 납부 현황 표는 세 개의 탭(`전체` / `미납 있음` / `납부 완료`)으로 회원을 추리고 있다. 기준월(`1~N월까지`)을 고를 수 있는 셀렉트는 **납부 완료 탭에서만** 노출됐고, 미납 탭은 항상 **1~12월 전체**를 기준으로 미납 여부를 판단했다.

운영 상 다음 한계가 있었다.

- **5월에 5월까지 미납자만 추리고 싶다** 같은 흐름이 불가능. 12월 기준이라 7~12월은 의무가 와도 아직 미납이라 자연스럽고, 운영자는 "지금 시점 기준으로 독촉 대상"을 표에서 직접 분리해야 했다.
- **납부 완료 탭과의 비대칭.** 같은 표 위에서 한 탭은 "선택한 달까지", 다른 탭은 "12월 전체 고정"이라 사용자가 매번 두 탭의 기준을 다시 떠올려야 했다.
- **탭 전환 시 셀렉트가 사라졌다 나타나는 깜빡임.** 셀렉트가 납부 완료 탭에서만 렌더링되어 레이아웃이 흔들렸다.

정책을 다음과 같이 정리했다.

> 미납·납부 완료 두 탭이 동일한 셀렉트(`기준월 throughMonth`)를 공유한다. 탭 전환 시 셀렉트는 같은 자리에 그대로 두고 안내 라벨만 바뀐다. '전체' 탭에서는 셀렉트를 숨긴다.

## 2. 도입한 개선

### 2-1. `paidThroughMonth` → `throughMonth` 리네이밍

상태 변수명을 두 탭이 공유하는 의미에 맞게 일반화했다. `defaultPaidThroughMonthForYear` → `defaultThroughMonthForYear`도 동일.

### 2-2. 미납 판정 헬퍼 추가 — `memberHasAnyUnpaidMonthThroughMonth`

`PaymentDashboardTable.tsx`에 헬퍼를 추가했다. 기존 `memberHasAnyUnpaidMonthInYear`(연 전체 기준)는 그대로 두고, 기준월을 받는 새 함수를 export한다.

```ts
export function memberHasAnyUnpaidMonthThroughMonth(
  member: MemberPaymentStatus,
  throughMonth: number
): boolean {
  if (member.type === 'exempt') return false;
  const months = member.obligationMonths
    ? member.obligationMonths.filter((m) => m <= throughMonth)
    : YEAR_MONTHS.filter(
        (m) => m >= (member.firstObligationMonth ?? 1) && m <= throughMonth
      );
  return months.some((month) => !member.payments[month]);
}
```

`memberFullyPaidThroughMonth`와 같은 슬라이싱 규칙(`obligationMonths`가 있으면 그것을 throughMonth까지 자르고, 없으면 `firstObligationMonth..throughMonth` 범위)으로 통일했다.

### 2-3. 셀렉트를 두 탭이 공유

`memberFilter === 'paid'`에서만 노출되던 셀렉트를 `unpaid`/`paid` 둘 다에서 노출하도록 분기 조건을 바꿨다. 라벨과 `aria-label`만 탭에 따라 달라진다.

| 탭 | 라벨 | `aria-label` |
| --- | --- | --- |
| 미납 있음 | `1월 ~ 선택한 달 사이 미납이 있는 회원만` | `미납 판정 기준 마지막 달` |
| 납부 완료 | `1월 ~ 선택한 달까지 모두 납부한 회원만` | `납부 완료 기준 마지막 달` |
| 전체 | (셀렉트 숨김 — 가벼운 안내문만) | — |

빈 상태 메시지도 동적으로 바뀐다. 예: `2026년 1~5월 사이 미납이 있는 일반·부부 회원이 없습니다.`

### 2-4. '전체' 탭의 안내문

기존 "미납: 1~12월 전체 기준" 고정 문구는 더 이상 정확하지 않으므로 '전체' 탭에서만 노출하는 일반 안내로 바꿨다.

```
미납·납부 완료 탭에서는 1월부터 선택한 달까지를 기준으로 일반·부부 회원만 추립니다.
```

## 3. 설계 의사결정

### 3-1. 셀렉트를 탭 안에 두고 공유하는 방식 vs 탭 밖으로 끌어올리는 방식

탭 위 한 줄에 `기준 월: [N월까지]`를 두고 두 탭이 시각적으로도 같은 위젯을 쓰는 안이 있었다. 거부한 이유:

- '전체' 탭에선 기준월이 의미가 없어 시각적 노이즈가 된다.
- 현재 구조에서도 셀렉트는 탭 내부 안내 라인에 있어 위치는 안정적이다. 라벨만 분기하면 충분하다.

### 3-2. `memberHasAnyUnpaidMonthInYear` 제거 대신 유지

새 헬퍼만으로도 동작은 가능하지만(`throughMonth=12`로 호출), 기존 함수가 외부에서 import되거나 의미가 다른 호출(연 전체 기준)에 쓰일 가능성을 고려해 둘 다 export로 둔다. 현재 호출자는 `index.tsx`뿐이라 중복은 미미하다.

### 3-3. 기본값 정책은 그대로

`defaultThroughMonthForYear(y)`는 당해년도면 현재월, 과거년도면 12월을 반환한다. 두 탭 모두 이 기본값을 공유한다.

- 당해년도 미납 탭: "지금까지 의무가 발생한 달 기준 미납자" — 운영자가 5월에 화면을 열면 1~5월 기준이 가장 자연스럽다.
- 과거년도 미납 탭: 12월까지 모든 의무가 끝났으므로 12월 기준이 자연스럽다.

연도 변경 시 `useEffect`로 `throughMonth`를 다시 기본값으로 리셋한다.

### 3-4. 미납 판정에 `throughMonth` 슬라이싱을 어떻게 적용했나

`memberFullyPaidThroughMonth`와 동일한 규칙을 사용했다. `obligationMonths`(서버에서 휴회 제외한 의무 월 배열을 내려주는 케이스)가 있으면 그것을 `m <= throughMonth`로 자르고, 없으면 `firstObligationMonth..throughMonth` 범위를 합성한다. 이렇게 두 함수의 슬라이싱이 정확히 같으므로 "1~5월까지 모두 납부 = 1~5월 사이 미납 0" 등치가 자연스럽게 성립한다.

## 4. 프런트 처리

### 4-1. `index.tsx`

```tsx
const [throughMonth, setThroughMonth] = useState(() =>
  defaultThroughMonthForYear(new Date().getFullYear())
);

useEffect(() => {
  setThroughMonth(defaultThroughMonthForYear(year));
}, [year]);
```

```tsx
{(memberFilter === 'unpaid' || memberFilter === 'paid') && (
  <div className="...">
    <span className="shrink-0">
      {memberFilter === 'paid'
        ? '1월 ~ 선택한 달까지 모두 납부한 회원만'
        : '1월 ~ 선택한 달 사이 미납이 있는 회원만'}
    </span>
    <select value={throughMonth} onChange={...} aria-label={...}>
      {/* 1~12월 옵션 */}
    </select>
  </div>
)}
```

```tsx
if (memberFilter === 'unpaid') {
  tableMembers = dashboard.members.filter((m) =>
    memberHasAnyUnpaidMonthThroughMonth(m, throughMonth)
  );
} else if (memberFilter === 'paid') {
  tableMembers = dashboard.members.filter((m) =>
    memberFullyPaidThroughMonth(m, throughMonth)
  );
}
```

| 케이스 | 표시 |
| --- | --- |
| 5월 기준, 1~5월 모두 납부한 회원 | 미납 탭에서 사라짐 / 납부 완료 탭에 노출 |
| 5월 기준, 3월만 미납 | 미납 탭에 노출 / 납부 완료 탭에서 사라짐 |
| 5월 기준, 7월 의무가 다가올 회원 (1~5월 모두 납부) | 미납 탭에서 사라짐 (7월은 throughMonth 밖) |
| 면제 회원 | 두 탭 모두에서 제외 (정책 동일) |
| 휴회 월만 있는 회원 | 의무가 없으므로 미납 탭에 노출 안 됨 |
| 탭 전환 (미납 ↔ 납부 완료) | 셀렉트는 같은 자리에 유지, 라벨만 변경 |
