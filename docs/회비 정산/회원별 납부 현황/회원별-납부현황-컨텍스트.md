# 회원별 납부 현황 — 화면 컨텍스트

작성/갱신일: 2026-10-10 (2026-11-29 납부 이력·내 회비 추가)
관련 화면: `/clubs/[id]/membership-fee`, `/clubs/[id]/my-fee`, `/clubs/[id]/members/[userId]`

회비 관리 대시보드 하단 "회원별 납부 현황" 표의 **현재 모습**을 한 페이지로 정리한다. 결정의 배경·이력은 [`기능/`](./기능/) 폴더에 있다.

## 1. 표 한 줄 = 한 명

표는 **개인 단위**다. 부부도 두 row로 나뉘며, 각 row는 본인의 의무·납부·휴회·탈퇴만 표시한다.

| 항목 | 단위 |
| --- | --- |
| 표의 한 행 | 개인 (`ClubMember` 1건) |
| `MembershipPayment` 저장 단위 | 개인. 같은 회원·같은 달에 두 건이 있을 수 있다(부족분을 나중에 채운 경우) — `@@index([clubMemberId, year, month])` |
| 부부 1건 입금이 두 사람에게 분배되는 시점 | 입금 처리(`confirm.ts`)에서 `tx.membershipPayment.create`를 두 번 호출 |
| 표시 시 부부 식별 | "부부" 배지 + 이름 셀 아래에 `(파트너이름)` 부기 |

## 2. 행 표시 규칙

| 셀 | 표시 내용 |
| --- | --- |
| 회원 이름 | 본인 이름 (회원 상세로 가는 링크). 부부면 아래 줄에 회색 작은 글씨로 `(파트너이름)`. 그 해에 입금을 시작했으면 `3월 입금 시작`, 그 해에 탈퇴했으면 `8월 탈퇴`를 같은 글씨로 한 줄씩 더한다 |
| 유형 | `일반` / `부부` / `면제` 중 하나 + 탈퇴 시 `탈퇴` 배지. 그 해에 면제 기간이 있으면(일부 기간이어도) `면제` |
| 1~12월 | 본인 기준 — 의무 없음 `-`, 휴회/병가, 미납 `X`(빨강), 납부 체크, 면제 `-`. 면제 기간의 달은 낸 기록이 있어도 면제 → [면제 기간](./기능/면제-기간.md) |
| 납부 있음 — 이월 필요 | 의무가 없는 달(휴회·가입 전·탈퇴 후)에 납부가 걸려 있으면 그 칸의 설명에 붙고 아이콘이 주의 색이 된다 → [납부월 이월](./기능/납부월-이월.md) |
| 입금 시작월 | 본인 `feeObligationStartAt`이 표시 연도와 같고 월이 2 이상이면 그 달 칸 왼쪽에 굵은 선(`accent`)과 이름 아래 `N월 입금 시작`. 휴회로 첫 의무월이 밀려도 실제 시작월에 긋는다 |
| 탈퇴월 | 그 해에 탈퇴했으면 그 달 칸 오른쪽에 굵은 빨간 선(`negative`)과 이름 아래 `N월 탈퇴`. 탈퇴월은 회원 관리에서 탈퇴로 바꿀 때 고른다(기본값은 마지막으로 낸 달) → [탈퇴월·재가입 시작월 고르기](./기능/탈퇴-재가입-처리.md) |
| 선의 뜻 범례 | 표 위에 선 견본과 `입금 시작월`·`탈퇴월`. 그 해에 그어진 선만 싣고, 선이 없으면 범례도 없다 |
| 납부 (n/m) | 본인 의무 월 가운데 면제가 아닌 달 중 납부한 비율. 1년 전체 면제는 회색 `-`, 의무 0은 회색, 완납은 초록, 절반 이상 파랑, 그 외 빨강 |

## 3. 데이터 산출 — `memberYearStatus`

모든 회원이 동일한 경로를 탄다. 부부 분기는 없다. **대시보드 API와 내보내기 API가 같은 조회·계산을 쓴다.**

| 단계 | 모듈 | 하는 일 |
| --- | --- | --- |
| 조회 | `memberYearStatusLoader.loadMemberYearData(prisma, clubId, year)` | 회원(APPROVED + 그 해 활동한 LEFT, 회비 대상 아님 제외), 휴회, 부부 그룹, 면제, 납부 내역을 한 번에 읽는다. 납부 금액은 통장 입금에 묶인 것만 `amountsByMonth`에 더하고, 직접 추가는 `manualPayments`로 따로 센다 |
| 계산 | `memberYearStatus.buildMemberYearStatus(year, member, today)` | 회원 한 명의 의무월·휴회월·납부 여부·칸 상태를 낸다 |

- 본인 `feeObligationStartAt` + 본인 `leavePeriods` + 본인 `leftAt`로 의무 월·휴회 월을 계산한다.
- `type`: 그 해 면제 기간이 있으면 → `exempt`, 부부 그룹 소속 → `couple`, 그 외 → `regular`.
- `exemptMonths`: 그 해 면제 기간의 달. `obligationMonths`(의무월)에는 면제 달도 남아 있다(내보내기가 의무월로 회원을 고른다).
- `paidCount`·`totalMonths`: 의무월 가운데 면제가 아닌 달로 센다.
- `couplePartnerName`: 부부면 파트너 이름, 아니면 `null`.
- `cells`(1~12월 칸의 상태)는 내보내기가 쓴다. `leaveReasons`는 2026-11-26부터 내보내기에 쓰지 않는다(병가 칸에 사유를 적지 않는다). **면제 기간의 달은 낸 기록이 있어도 면제다.** 그 앞의 달은 일반 회원처럼 완납·미납이다.
- `orphanPaidMonths`: 의무가 없는데 납부가 걸려 있는 달. 면제 달은 의무가 있는 달이라 여기에 들지 않는다(이월 대상이 아니다).

## 4. 요약 통계 단위

`summary.totalMembers` / `monthlyStats[m].totalCount` / `monthlyStats[m].paidCount`는 **모두 개인 단위**다.

| 필드 | 의미 |
| --- | --- |
| `summary.totalMembers` | 클럽 회원 수 (개인). 회비 대상 아님 회원은 빠진다 → [회비 대상 아님](./기능/회비-대상-아님.md) |
| `summary.exemptMembers` | 그 해에 면제 기간이 있는 회원 수 (개인) |
| `summary.coupleGroups` | 부부 **그룹** 수 (이 필드만 그룹 단위 — 명칭상 그대로 둠) |
| `monthlyStats[m].totalCount` | 해당 월 의무가 있고 면제가 아닌 회원 수 (개인) |
| `monthlyStats[m].paidCount` | 해당 월 납부한 회원 수 (개인). 직접 추가한 납부도 센다 |
| `monthlyStats[m].amount`, `summary.yearTotal` | 통장 입금에 묶인 납부의 금액 합계 |
| `summary.manualPayments` | 직접 추가한 납부(통장 입금 없음)의 건수·금액. 총 수입 아래에 따로 보인다 → [납부 직접 추가](./기능/납부-직접-추가.md) |

## 5. 미납 회원 목록 — `unpaid.ts`

리포트 페이지의 "미납 회원 목록"도 같은 정책. 회비 대상 아님 회원은 뺀다. 본인의 의무·납부 여부만으로 미납 판단한다. 그 달이 면제 기간인 회원은 뺀다(연중에 면제가 된 회원은 그 전 달까지 미납 대상). 응답에는 `partnerName`이 부기로 들어가 화면에서 부부 식별이 가능하다.

리포트의 "회원별 연간 납부"는 1년 전체 면제 회원만 빼고, 연중에 면제가 된 회원은 면제 앞의 달로 싣는다.

## 6. 필터 동작 (`index.tsx`)

탭 전환은 `memberFilter` 상태(`'all' | 'unpaid' | 'paid'`)로, 기준월은 `throughMonth` 상태로 관리된다. 미납·납부 완료 두 탭이 같은 셀렉트(`1월 ~ N월까지`)를 공유하며 라벨만 분기된다. 연도 변경 시 `throughMonth`는 그 연도의 기본값(당해년도면 현재월, 과거년도면 12월)으로 리셋된다.

| 필터 | 기준 | 셀렉트 |
| --- | --- | --- |
| 전체 | 모든 회원 row | 숨김 |
| 미납 있음 | `memberHasAnyUnpaidMonthThroughMonth(m, throughMonth)` — 1~throughMonth 사이 의무 월 중 한 달이라도 미납 | 노출 (`미납 판정 기준 마지막 달`) |
| 납부 완료 | `memberFullyPaidThroughMonth(m, throughMonth)` — 1~throughMonth 사이 의무 월을 모두 납부 | 노출 (`납부 완료 기준 마지막 달`) |

두 헬퍼는 `obligationMonths`가 있으면 `m <= throughMonth`로 잘라 쓰고, 없으면 `firstObligationMonth..throughMonth` 범위를 합성한다. 거기서 면제 달(`exemptMonths`, 없으면 `type === 'exempt'`일 때 1년 전체)을 뺀다. 슬라이싱이 동일해 "1~N월 모두 납부 = 1~N월 사이 미납 0" 등치가 성립한다. 단, 그 기간이 모두 면제인 회원은 납부 완료에 넣지 않는다.

부부도 개인 row이므로 한 명만 미납이면 그 사람만 "미납 있음"에 잡힌다.

## 7. 정렬

활동 회원 → 탈퇴 회원 순. 탈퇴 회원 시작 지점에 `탈퇴 회원` 구분 row 삽입.

## 7-1. 화면 구성

- **페이지(`index.tsx`)는 데이터를 읽어 `FeeDashboardView`에 넘기기만 한다.**
  - View는 최근 업로드 카드, 바로가기 6개, 회비 설정 안내, 연도 줄([납부현황 내보내기]·[이미지로 내보내기] 버튼), 요약 카드, 납부 현황 격자를 그린다.
- **최근 업로드 카드는 남은 일을 보여 준다.**
  - "미확정 N건 · 미매칭 N건 · 검토 필요 N건". 누르면 그 건들만 걸러진 입금 내역 처리 화면으로 간다.
  - 건수는 보고 있는 해와 상관없이 클럽 전체이고, 검토 필요는 조회할 때 다시 계산한 값이다(`latestUpload.pendingWork`).
  - 보기 방식(전체·미납 있음·납부 완료)은 `SegmentedControl`, 기준 달은 `OptionPicker`.
- **격자(`PaymentDashboardTable`)는 `DataTable`을 쓰지 않는다.**
  - 열이 15개라 휴대폰 리스트 전환이 맞지 않고, 이름 열 고정이 필요하다. 휴대폰에서는 가로로 민다.
  - 칸은 lucide 아이콘으로 그린다: 납부 `Check`, 미납 `X`, 면제·의무 없음 `Minus`, 휴회 `Hospital`. 칸의 `title`과 `aria-label`로 뜻을 알린다.
  - 입금 시작월·탈퇴월의 굵은 세로선은 뜻이 칸에 마우스를 올려야만 보여 휴대폰에서 알 수 없었다. 2026-11-02부터 표 위 범례와 이름 아래 글자로 함께 알린다. 휴대폰에서 가로로 밀어 선이 화면 밖에 있어도 이름 아래 글자로 알 수 있다.
- 결정의 배경은 [디자인 시스템 전환](../입금%20내역%20처리/기능/디자인-시스템-전환.md).

## 7-2. 납부현황 내보내기

- **[납부현황 내보내기] 버튼이 보고 있는 해의 표를 엑셀로 내려 준다.** (`GET /api/clubs/[id]/membership-fee/export?year=`)
  - 재무의 기존 표와 같은 모양: 제목·반영일·범례·NO/성명/1~12월/비고.
  - 직책이 있는 회원이 정렬 순서대로 위쪽에, 나머지는 가나다순, 탈퇴 회원은 아래에 따로.
- **직책과 정렬 순서는 회원 상세에서 고친다.** (`ClubMember.position`, `positionOrder`)
- 자세한 내용은 [납부현황 내보내기](./기능/납부현황-내보내기.md).
- **[이미지로 내보내기] 버튼이 같은 표를 카톡에 올릴 PNG로 만든다.** (`GET /api/clubs/[id]/membership-fee/export-sheet?year=`로 줄을 받아 브라우저가 그린다)
  - 40명씩 나눈 장마다 제목·반영일·범례·머리글·쪽 번호가 있다. 가로 1600px.
  - 지금 회원만 싣는다. 탈퇴 회원은 엑셀에만 있다.
  - 휴대폰은 확인 창의 [공유하기]로 공유 창(카톡)을 열고, PC는 내려받는다.
  - 줄 순서·비고·칸 색은 엑셀과 같은 `buildFeeStatusSheet`에서 온다.
  - 자세한 내용은 [납부현황 이미지 내보내기](./기능/납부현황-이미지-내보내기.md).

## 7-3. 회원별 납부 이력 (내 회비 · 회원 상세)

- **같은 칸 계산(`memberYearStatus`)으로 회원 한 명의 한 해를 달별 목록으로 보인다.**
  - 회원은 메뉴의 "내 회비"(`/clubs/[id]/my-fee`)에서 자기 것만, 임원은 회원 상세의 "납부 이력"에서 그 회원 것을 본다.
  - API는 `GET /api/clubs/[id]/members/[userId]/fee-history?year=` 하나이고, 임원이거나 본인만 통과한다.
- **화면 위에서부터: 반영 시각·연도 → 미납 요약·월 회비 → 확인 중인 입금 → 달별 납부 → 휴회(내 회비만).**
  - 낸 달에는 금액·입금일(한국 시각)·입금자명(회원 이름과 다를 때)·부부가 붙는다. 직접 추가는 "직접 추가 · 사유"다.
  - "내 회비" 메뉴는 활성 회비 유형이 있는 클럽에서만 보인다(`custom/menu`의 `feeMenuEnabled`).
- 자세한 내용은 [내 회비 · 회원별 납부 이력](./기능/내-회비-납부-이력.md).
