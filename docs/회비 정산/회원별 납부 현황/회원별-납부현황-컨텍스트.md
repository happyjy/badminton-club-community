# 회원별 납부 현황 — 화면 컨텍스트

작성/갱신일: 2026-10-10
관련 화면: `/clubs/[id]/membership-fee`

회비 관리 대시보드 하단 "회원별 납부 현황" 표의 **현재 모습**을 한 페이지로 정리한다. 결정의 배경·이력은 [`기능/`](./기능/) 폴더에 있다.

## 1. 표 한 줄 = 한 명

표는 **개인 단위**다. 부부도 두 row로 나뉘며, 각 row는 본인의 의무·납부·휴회·탈퇴만 표시한다.

| 항목 | 단위 |
| --- | --- |
| 표의 한 행 | 개인 (`ClubMember` 1건) |
| `MembershipPayment` 저장 단위 | 개인. 같은 회원·같은 달에 두 건이 있을 수 있다(부족분을 나중에 채운 경우) — `@@index([clubMemberId, year, month])` |
| 부부 1건 입금이 두 사람에게 분배되는 시점 | 입금 처리(`confirm.ts`)에서 `tx.membershipPayment.create`를 두 번 호출 |
| 표시 시 부부 식별 | "부부" 배지 + 이름 셀 아래에 `(파트너이름)` 부기 |

## 2. 행 표시 규칙

| 셀 | 표시 내용 |
| --- | --- |
| 회원 이름 | 본인 이름 (회원 상세로 가는 링크). 부부면 아래 줄에 회색 작은 글씨로 `(파트너이름)` |
| 유형 | `일반` / `부부` / `면제` 중 하나 + 탈퇴 시 `탈퇴` 배지 |
| 1~12월 | 본인 기준 — 의무 없음 `-`, 휴회/병가, 미납 `X`(빨강), 납부 체크 |
| 납부 있음 — 이월 필요 | 의무가 없는 달(휴회·가입 전·탈퇴 후)에 납부가 걸려 있으면 그 칸의 설명에 붙고 아이콘이 주의 색이 된다 → [납부월 이월](./기능/납부월-이월.md) |
| 시작월 강조 | 본인 `feeObligationStartAt`이 표시 연도와 같고 월이 2 이상이면 그 월에 좌측 파란 보더 |
| 탈퇴월 강조 | 본인 탈퇴월에 우측 빨간 보더 |
| 납부 (n/12) | 본인 의무 월 중 납부한 비율. 의무 0이거나 면제는 회색 `-`, 완납은 초록, 절반 이상 파랑, 그 외 빨강 |

## 3. 데이터 산출 — `memberYearStatus`

모든 회원이 동일한 경로를 탄다. 부부 분기는 없다. **대시보드 API와 내보내기 API가 같은 조회·계산을 쓴다.**

| 단계 | 모듈 | 하는 일 |
| --- | --- | --- |
| 조회 | `memberYearStatusLoader.loadMemberYearData(prisma, clubId, year)` | 회원(APPROVED + 그 해 활동한 LEFT), 휴회, 부부 그룹, 면제, 납부 내역을 한 번에 읽는다 |
| 계산 | `memberYearStatus.buildMemberYearStatus(year, member, today)` | 회원 한 명의 의무월·휴회월·납부 여부·칸 상태를 낸다 |

- 본인 `feeObligationStartAt` + 본인 `leavePeriods` + 본인 `leftAt`로 의무 월·휴회 월을 계산한다.
- `type`: 면제 → `exempt`, 부부 그룹 소속 → `couple`, 그 외 → `regular`.
- `couplePartnerName`: 부부면 파트너 이름, 아니면 `null`.
- `cells`(1~12월 칸의 상태)와 `leaveReasons`는 내보내기가 쓴다. **면제 회원도 실제로 낸 달은 완납이다.**
- `orphanPaidMonths`: 의무가 없는데 납부가 걸려 있는 달.

## 4. 요약 통계 단위

`summary.totalMembers` / `monthlyStats[m].totalCount` / `monthlyStats[m].paidCount`는 **모두 개인 단위**다.

| 필드 | 의미 |
| --- | --- |
| `summary.totalMembers` | 클럽 회원 수 (개인) |
| `summary.exemptMembers` | 면제 회원 수 (개인) |
| `summary.coupleGroups` | 부부 **그룹** 수 (이 필드만 그룹 단위 — 명칭상 그대로 둠) |
| `monthlyStats[m].totalCount` | 해당 월 의무가 있는 회원 수 (개인) |
| `monthlyStats[m].paidCount` | 해당 월 납부한 회원 수 (개인) |

## 5. 미납 회원 목록 — `unpaid.ts`

리포트 페이지의 "미납 회원 목록"도 같은 정책. 본인의 의무·납부 여부만으로 미납 판단한다. 응답에는 `partnerName`이 부기로 들어가 화면에서 부부 식별이 가능하다.

## 6. 필터 동작 (`index.tsx`)

탭 전환은 `memberFilter` 상태(`'all' | 'unpaid' | 'paid'`)로, 기준월은 `throughMonth` 상태로 관리된다. 미납·납부 완료 두 탭이 같은 셀렉트(`1월 ~ N월까지`)를 공유하며 라벨만 분기된다. 연도 변경 시 `throughMonth`는 그 연도의 기본값(당해년도면 현재월, 과거년도면 12월)으로 리셋된다.

| 필터 | 기준 | 셀렉트 |
| --- | --- | --- |
| 전체 | 모든 회원 row | 숨김 |
| 미납 있음 | `memberHasAnyUnpaidMonthThroughMonth(m, throughMonth)` — 1~throughMonth 사이 의무 월 중 한 달이라도 미납 | 노출 (`미납 판정 기준 마지막 달`) |
| 납부 완료 | `memberFullyPaidThroughMonth(m, throughMonth)` — 1~throughMonth 사이 의무 월을 모두 납부 | 노출 (`납부 완료 기준 마지막 달`) |

두 헬퍼는 `obligationMonths`가 있으면 `m <= throughMonth`로 잘라 쓰고, 없으면 `firstObligationMonth..throughMonth` 범위를 합성한다. 슬라이싱이 동일해 "1~N월 모두 납부 = 1~N월 사이 미납 0" 등치가 성립한다.

부부도 개인 row이므로 한 명만 미납이면 그 사람만 "미납 있음"에 잡힌다.

## 7. 정렬

활동 회원 → 탈퇴 회원 순. 탈퇴 회원 시작 지점에 `탈퇴 회원` 구분 row 삽입.

## 7-1. 화면 구성

- **페이지(`index.tsx`)는 데이터를 읽어 `FeeDashboardView`에 넘기기만 한다.**
  - View는 최근 업로드 카드, 바로가기 6개, 회비 설정 안내, 연도 줄([납부현황 내보내기] 버튼), 요약 카드, 납부 현황 격자를 그린다.
- **최근 업로드 카드는 남은 일을 보여 준다.**
  - "미확정 N건 · 미매칭 N건 · 검토 필요 N건". 누르면 그 건들만 걸러진 입금 내역 처리 화면으로 간다.
  - 건수는 보고 있는 해와 상관없이 클럽 전체이고, 검토 필요는 조회할 때 다시 계산한 값이다(`latestUpload.pendingWork`).
  - 보기 방식(전체·미납 있음·납부 완료)은 `SegmentedControl`, 기준 달은 `OptionPicker`.
- **격자(`PaymentDashboardTable`)는 `DataTable`을 쓰지 않는다.**
  - 열이 15개라 휴대폰 리스트 전환이 맞지 않고, 이름 열 고정이 필요하다. 휴대폰에서는 가로로 민다.
  - 칸은 lucide 아이콘으로 그린다: 납부 `Check`, 미납 `X`, 면제·의무 없음 `Minus`, 휴회 `Hospital`. 칸의 `title`과 `aria-label`로 뜻을 알린다.
- 결정의 배경은 [디자인 시스템 전환](../입금%20내역%20처리/기능/디자인-시스템-전환.md).

## 7-2. 납부현황 내보내기

- **[납부현황 내보내기] 버튼이 보고 있는 해의 표를 엑셀로 내려 준다.** (`GET /api/clubs/[id]/membership-fee/export?year=`)
  - 재무의 기존 표와 같은 모양: 제목·반영일·범례·NO/성명/1~12월/비고.
  - 직책이 있는 회원이 정렬 순서대로 위쪽에, 나머지는 가나다순, 탈퇴 회원은 아래에 따로.
- **직책과 정렬 순서는 회원 상세에서 고친다.** (`ClubMember.position`, `positionOrder`)
- 자세한 내용은 [납부현황 내보내기](./기능/납부현황-내보내기.md).
