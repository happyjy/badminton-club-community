# 회비 정산 관리 시스템 - 요구사항

## 1. 개요

| 항목   | 내용                       |
| ------ | -------------------------- |
| 목적   | 클럽 회비 납부 관리 자동화 |
| 대상   | 당산클럽 회원 약 90명      |
| 관리자 | 총무                       |

---

## 2. 회비 유형 시스템

유연한 회비 유형(FeeType)을 지원하며, 유형별·연도별·납부주기별로 금액을 설정할 수 있다.

### 2.1 기본 유형

| 유형      | 월 회비  | 비고                              |
| --------- | -------- | --------------------------------- |
| 일반 회원 | 25,000원 | FeeType "일반"                    |
| 부부 회원 | 45,000원 | FeeType "부부", 한 행으로 표시    |
| 면제      | -        | FeeExemption, 회비 납부 의무 없음 |

### 2.2 회비 유형 확장

- FeeType은 관리자가 자유롭게 추가/수정/비활성화 가능 (예: "학생", "주말회원" 등).
- 각 유형은 연도별로 납부주기(MONTHLY, QUARTERLY, SEMI_ANNUAL, ANNUAL)에 따른 금액(FeeRate)을 설정.
- 회원별로 하나의 회비 유형을 지정(MemberFeeType, 1인 1유형).

### 2.3 금액 검증

- 입금액이 해당 회원 유형의 FeeRate 배수인지 검증.
- FeeRate 목록에서 일치하는 주기를 자동 탐지(detectFeeType).
- 배수가 아닌 경우에도 매칭된 회원이 있으면 MATCHED 상태로 저장 (부족/초과 처리 지원).

## 3. 회비 의무 규칙

### 3.1 의무 시작 (가입 시기 반영)

- `ClubMember.feeObligationStartAt` 기준으로 해당 월부터 의무 (일자 무관, 월 단위).
- 미설정 시 당해 연도 1월부터 의무 (하위 호환).
- 관리자가 회원 상세에서 조정 가능.
- 상세: [회비-의무-시작-규칙.md](회비-의무-시작-규칙.md)

### 3.2 휴회/병가 (MemberLeave)

- 회원별로 휴회 기간(startYear/startMonth ~ endYear/endMonth)을 등록.
- 종료 미입력(null) 시 장기/미정으로 간주, 시작월 이후 모두 휴회.
- 휴회 기간에 해당하는 월은 회비 의무에서 제외.
- 대시보드에서 휴회 월은 "의무 없음"으로 표시.

### 3.3 부부 회원

- 부부 행의 의무 시작월은 **둘 중 늦은 의무 시작월** 기준.
- 양쪽 휴회 기간을 합산하여 의무 월 산출.

## 5. 기능 목록

### 5.1 설정 기능

| 기능             | 설명                                                  |
| ---------------- | ----------------------------------------------------- |
| 회비 유형 관리   | FeeType CRUD (이름, 설명, 활성 여부, 정렬 순서)       |
| 회비 금액 관리   | FeeRate 설정 (유형 + 연도 + 납부주기별 금액)          |
| 회원 유형 지정   | MemberFeeType - 회원별 회비 유형 배정                 |
| 부부 회원 설정   | CoupleGroup - 두 회원을 부부로 묶기/해제              |
| 회비 면제 설정   | FeeExemption - 연도별 면제 대상 지정 (사유 포함)      |
| 회비 의무 시작일 | feeObligationStartAt - 회원별 가입 시기 반영          |
| 휴회/병가 관리   | MemberLeave - 회원별 휴회 기간 등록/해제              |

### 5.2 입금 처리 (하이브리드 방식)

| 단계         | 처리 방식                                         |
| ------------ | ------------------------------------------------- |
| 1. 업로드    | 카카오뱅크 엑셀 파일 업로드 (배치 단위)           |
| 2. 자동 파싱 | 거래내역 추출 (거래일시, 입금자명, 금액, 메모)    |
| 3. 자동 매칭 | 입금자명 → 회원 매칭 시도 (7단계 매칭 알고리즘)   |
| 4. 자동 제안 | 금액 검증 + 배정 월 제안 (미납 월 + 최종납부월 기준) |
| 5. 총무 확인 | 매칭 결과 검토, 필요시 수정                       |
| 6. 확정      | 납부 내역으로 저장 (단건/일괄 확정)               |

### 5.3 회원 매칭 알고리즘

입금자명 → 회원 자동 매칭 시 7단계 우선순위:

1. **정확 일치** - 이름 완전 일치
2. **부부 매칭** - 입금자명에 두 명 이름 모두 포함
3. **부분 일치** - 입금자명에 회원 이름 포함
4. **성 생략** - 성 제외한 이름만 일치
5. **2글자 이름 성 생략** - 2자 이름 특수 처리
6. **부부 단일** - 부부 중 한 명만 일치
7. **유사도** - 레벤슈타인 거리 ≤ 1 (오타 허용)

각 단계별 confidence(0~1) 반환.

### 5.4 대시보드

| 기능             | 설명                                        |
| ---------------- | ------------------------------------------- |
| 회원별 납부 현황 | 회원 × 12개월 매트릭스 (의무 월만 집계)     |
| 월별 납부율      | 해당 월 납부 완료 비율 (의무 회원 기준)     |

| 휴회 표시        | 휴회 기간은 "의무 없음"으로 시각적 구분     |

## 7. DB 스키마

```prisma
// 납부 주기
enum FeePeriod {
  MONTHLY      // 월납 (1개월)
  QUARTERLY    // 분기납 (3개월)
  SEMI_ANNUAL  // 반기납 (6개월)
  ANNUAL       // 연납 (12개월)
}

enum PaymentRecordStatus {
  PENDING    // 대기
  MATCHED    // 매칭됨
  ERROR      // 에러
  CONFIRMED  // 확정
  SKIPPED    // 건너뜀
}

// 회비 유형 (일반, 부부, 학생 등)
model FeeType {
  id          Int      @id @default(autoincrement())
  clubId      Int
  name        String   // "일반", "부부" 등
  description String?
  isActive    Boolean  @default(true)
  sortOrder   Int      @default(0)

  rates   FeeRate[]
  members MemberFeeType[]
  @@unique([clubId, name])
}

// 회비 금액 (유형 + 연도 + 납부주기별)
model FeeRate {
  id         Int       @id @default(autoincrement())
  feeTypeId  Int
  year       Int
  period     FeePeriod
  amount     Int       // 해당 주기의 총 금액
  monthCount Int       // 적용 개월 수 (1, 3, 6, 12)

  @@unique([feeTypeId, year, period])
}

// 회원별 회비 유형 (1인 1유형)
model MemberFeeType {
  id           Int @id @default(autoincrement())
  clubMemberId Int @unique
  feeTypeId    Int
}

// 부부 그룹
model CoupleGroup {
  id      Int @id @default(autoincrement())
  clubId  Int
  members CoupleMember[]
}

// 부부 그룹 멤버
model CoupleMember {
  id            Int @id @default(autoincrement())
  coupleGroupId Int
  clubMemberId  Int @unique // 1인 1그룹
}

// 회비 면제 (연도별)
model FeeExemption {
  id           Int    @id @default(autoincrement())
  clubMemberId Int
  year         Int
  reason       String // "임원" 등
  createdById  Int

  @@unique([clubMemberId, year])
}

// 휴회/병가 기간
model MemberLeave {
  id           Int    @id @default(autoincrement())
  clubMemberId Int
  startYear    Int
  startMonth   Int    // 1~12
  endYear      Int?   // null = 미정/장기
  endMonth     Int?   // 1~12
  reason       String?
}

// 입금 배치 (엑셀 업로드 단위)
model PaymentUploadBatch {
  id           String @id @default(cuid())
  clubId       Int
  uploadedById Int
  fileName     String
  recordCount  Int
  records      PaymentRecord[]
}

// 입금 내역 (엑셀 파싱 결과)
model PaymentRecord {
  id              String              @id @default(cuid())
  batchId         String
  clubId          Int
  transactionDate DateTime
  depositorName   String
  amount          Int
  memo            String?
  matchedMemberId Int?                // 하위 호환
  status          PaymentRecordStatus @default(PENDING)
  errorReason     String?

  matchedMembers PaymentRecordMatchedMember[] // 다중 매칭
  payments       MembershipPayment[]
}

// 입금-회원 다대다 매칭
model PaymentRecordMatchedMember {
  id              String @id @default(cuid())
  paymentRecordId String
  clubMemberId    Int

  @@unique([paymentRecordId, clubMemberId])
}

// 납부 내역 (확정)
model MembershipPayment {
  id              String    @id @default(cuid())
  clubMemberId    Int
  paymentRecordId String
  year            Int
  month           Int       // 1~12
  amount          Int
  period          FeePeriod @default(MONTHLY)
  confirmedAt     DateTime  @default(now())
  confirmedById   Int

  @@unique([clubMemberId, year, month])
}

// ClubMember 확장 필드
// feeObligationStartAt DateTime? — 회비 의무 시작 시점 (해당 월부터)
```

## 11. 참고사항

- 입금 방식: 카카오뱅크 비즈니스 계좌 (카카오페이 송금 + 계좌이체)
- 현재 관리 방식: 엑셀 수동 관리 → 시스템 자동화
- 납부 기한: 없음 (자율)
- 의무 계산 유틸: `src/lib/membership-fee/feeObligation.ts`
- 매칭 유틸: `src/lib/membership-fee/memberMatcher.ts`
- 금액 검증 유틸: `src/lib/membership-fee/amountValidator.ts`
- 월 제안 유틸: `src/lib/membership-fee/monthSuggester.ts`
