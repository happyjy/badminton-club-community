- **목록에 없던 차이도 찾아 고쳤다.**
  - 열어 둔 건이 목록에서 빠졌다가 다시 나타나면 시트가 저절로 열렸다 → 목록에서 빠지면 열림 상태를 지운다.
  - 면제 삭제 중에 다른 행을 눌러 삭제를 겹쳐 보낼 수 있었다 → 삭제 중에는 묻지 않는다.

  - 대시보드의 휴회 칸이 시작월·탈퇴월과 겹치면 휴회 안내가 가려졌다 → 아이콘에 따로 단다.
- **고치지 않고 남긴 차이**
  - 업로드 이력의 행이 링크에서 버튼으로 바뀌어 새 탭으로 열 수 없다 (`DataTable`의 행 클릭 방식).
  - 업로드 화면의 검토 표, 업로드 이력, 리포트(회원별), 설정 표에 머리글 정렬이 새로 생겼다.
  - 휴회 삭제는 확인창의 답을 기다리지 않고 수정 시트를 먼저 닫는다.
- **확인하지 못한 것**
  - 실제 데이터로 하는 쓰기 동작(확정·삭제·업로드). 프로덕션 DB라 테스트와 미리보기(가짜 데이터)로만 검증했다.
