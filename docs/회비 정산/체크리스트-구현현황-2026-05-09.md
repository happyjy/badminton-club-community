| 우선순위            | 항목                                                 | 이유                                                  |

| 🔴 높음             | 부부 한 명 병가 시 나머지 25,000원 자동 전환         | 회비 정확성에 직결, 미반영 시 매월 잘못 청구가 반복됨 |
